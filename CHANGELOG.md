# Lucky Jet — история обновлений

## v0.9 — 2026-11-08 — Независимая сводка архива

- Вкладка «Главная»: раскрываемая сводка получает собственное количество раундов (1–50 000), собственный целевой коэффициент X (включительно) и отдельный X для отсчёта с последнего совпадения.
- Сохраняются настройки в браузере пользователя; доступны быстрые значения коэффициентов.
- Анализ строго по неизменяемому архиву завершённых раундов в Redis Stream, без DEMO, стратегии и ограничения плиток коэффициентов.
- Подсчёт совпадений, текущего ожидания, среднего/минимального/максимального интервала, максимальной серии без X, средних/максимальных коэффициентов, количества <2x и сравнение с предыдущим аналогичным периодом.
- История до 50 последних совпадений: коэффициент, позиция, время фиксации архивом, интервал до предыдущего (только при подтверждённой непрерывности).
- Пропуски, повторы и недостаточная глубина архива обозначаются; никакие неизвестные результаты не додумываются.
- Сводка загружается отдельно, не останавливает сборщики статистики и не изменяет историю.
- Контрольные тесты для чисел, разрывов, повторов, прав доступа и независимости интерфейса.

**Обратная совместимость:** изменена только сводка; DEMO, кошельки, пользовательская история и API старых вкладок без изменений.

**Исходная точка для отката:** ветка `backup/2026-11-08-before-independent-summary`, коммит `de9fdafb8bc1c8c978ba2e7fce358ac9919c3f84`.

**Ограничение:** данные отражают сохранённые события, но сама полнота истории стороннего сайта не гарантируется. Для защиты Redis на один запрос ограничение — 50 000 раундов.
