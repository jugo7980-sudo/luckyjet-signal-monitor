## Версия 0.2.0 — вторая DEMO-стратегия
- Добавлена **независимая** стратегия после коэффициента строго выше заданного (первоначально >x100).
- Выбор числа завершённых раундов ожидания (по умолчанию 100).
- После полного ожидания — фиксированная виртуальная ставка **каждый следующий раунд** до автовывода по выбранному коэффициенту (по умолчанию x100).
- В отличие от существующей стратегии «серия <2x», **догон / удвоение в новой стратегии не используется**.
- Каждый цикл и валюта сохраняются в независимом архиве, не очищаемом сбросами DEMO.
- Две сворачиваемые стратегии и раздельные счётчики/журналы используют общий виртуальный баланс.
- Финансовый итог каждого цикла считается только по его собственным ставкам и выплатам.
- При разрыве исходной истории новые ставки блокируются, чтобы не выдумывать результаты.
- Бэкап и контрольный SHA предыдущей версии закреплены в этом реестре.

### Правила выпуска, которые сохраняются для следующих версий
1. Перед публикацией: новый проверенный снимок Redis, фиксация текущего кода, конфигурации и deployment ID.
2. Изменения в отдельной ветке; все тесты и проверка браузера до merge.
3. Новая версия получает собственный номер, дату и список изменений.
4. Сборщики и Redis не перезапускаются при обычном выпуске сайта.
5. **Никакого автоматического отката.** По запросу пользователя откатывается выбранная версия кода; восстановление более старой базы отдельно согласуется во избежание уничтожения новых архивных данных.

## v0.2.26 — Стратегия №4: новый сигнал после каждого поражения и фактическая прибыль (2026-11-08)
- Вход: N подряд завершённых коэффициентов строго ниже выбранного X; первая и каждая следующая ставка выполняются на **следующем**, а не на уже завершённом раунде.
- После проигрыша новая ставка не идёт сразу: снова требуются N **новых** подряд раундов ниже X; выпадение X или выше обнуляет ожидание. Сумма следующей ставки сохраняется между сигналами, в том числе после восстановления состояния.
- Для стратегии №4 убрано отдельное ограничение X до 1.49: применяется общий допустимый диапазон X 1.01–10000.
- Начальная ставка не является дополнительной целью чистой прибыли. Для восстановления убытков используется чистая прибыль **первой выигравшей ставки** при выбранном X. Пример: начальная 1000 KRW, X=1.38 → целевая чистая прибыль цикла 380 KRW; после первой потери следующая ставка 3632 KRW (после нового сигнала), выигрыш даёт итог +380 KRW.
- Сессия завершается сразу при выигравшем раунде, показывает реальную чистую прибыль и возвращается в режим ожидания нового сигнала. Нет отдельного параметра +1000 KRW.
- Миграция старых неоконченных циклов №4 предотвращает немедленную ставку после проигрыша. История ставок, общий архив, уведомления, фактические коэффициенты, баланс и стратегии №1–№3 сохранены.

## v0.2.27 — Живые мини-плашки четырёх DEMO-стратегий (2026-11-08)
- На главной под коэффициентами: ровно четыре фиксированные мини-плашки в один горизонтальный ряд (№1–№4), без увеличения/переноса. Верхняя точка — достоверное активное состояние; середина — фактический прогресс или ставка; нижняя строка — чистый результат.
- Каждая стратегия считает текущий/последний результат **только из собственных записей ставок**: выплата − ставки, не из общего баланса. При завершении/остановке сохраняется последний фактический результат до следующей ставки; после сброса DEMO старая сумма не переносится. Нет подтверждённых данных — «—».
- Одна компактная выдвижная панель шириной максимум 350px. Внутри: состояние, коэффициент, последнее действие, финансовый результат; крестик справа сверху; три одинаковых по ширине кнопки-иконки (питание, настройки, история). Питание зелёное при включении, красное при выключении.
- Отключение из панели фиксируется сервером немедленно (в том числе для активной стратегии №1) с сохранением фактических убытков/результата в её истории. Настройки и история ведут в уже существующие разделы именно выбранной стратегии.
- При переходе в другую вкладку панель автоматически закрывается и не открывается сама после возврата. Нижнее меню остаётся доступным для перехода при открытой панели. Закрытие панели не управляет стратегией и не затрагивает фоновый мониторинг.
- Достоверность: при недоступном/устаревшем потоке или неподтверждённом DEMO-балансе не рисуем зелёную точку, не выдаём старые суммы за текущие данные. Новые браузерные и серверные регрессионные тесты.
- Резерв исходного main: `backup/2026-11-08-v0.2.26-before-strategy-live-tiles` (SHA `2d8dc41741fa91fc7b09c90f453d7736822b9490`).
