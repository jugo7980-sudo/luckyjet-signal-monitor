## Версия 0.2.0 — вторая DEMO-стратегия
- Добавлена **независимая** стратегия после коэффициента строго выше заданного (первоначально >x100).
- Выбор числа завершённых раундов ожидания (по умолчанию 100).
- После полного ожидания — фиксированная виртуальная ставка **каждый следующий раунд** до автовывода по выбранному коэффициенту (по умолчанию x100).
- В отличие от существующей стратегии «серия <2x», **догон / удвоение в новой стратегии не используется**.
- Каждый цикл и валюта сохраняются в независимом архиве, не очищаемом сбросами DEMO.
- Две сворачиваемые стратегии и раздельные счётчики/журналы используют общий виртуальный баланс.
- Финансовый итог каждого цикла считается только по его собственным ставкам и выплатам.
- При разрыве исходной истории новые ставки блокируются, чтобы не выдумывать результаты.
- Бэкап и контрольный SHA предыдущей версии закреплены в этом реестре.

## Версия 0.2.1 — 2026-11-08 — независимая сводка архива
- Сводка на «Главной» рассчитывается **только по фактическому Redis Stream**, независимо от настроек последних коэффициентов, двух DEMO-стратегий, баланса и сбросов истории.
- Три отдельные настройки: глубина анализа 1–50 000 завершённых сохранённых раундов, искомый порог ≥ X, порог ≥ X для счётчика после последнего совпадения.
- Поиск совпадений, интервалов между X, среднего/максимального коэффициента, максимального ожидания, количества ниже 2x и сравнение с предыдущими N раундами.
- Показано до 50 последних совпадений, московское время не используется: время фиксации переведено во Владивосток.
- Настройки сохраняются в браузере; пересчёт выполняется отдельно от сбора статистики.
- Пропуски, дубли, недоступная глубина поиска и недостаточная достоверность времени показываются явно, без придумывания результатов.
- Работа обеих DEMO-стратегий версии 0.2.0 и их журналы сохранены без изменения.
- Контрольная ветка до начала работ: `backup/2026-11-08-before-independent-summary`, SHA `de9fdafb8bc1c8c978ba2e7fce358ac9919c3f84`.
- Подготовлено в отдельной ветке на базе версии 0.2.0, протестировано через GitHub Actions.
- Статистика описывает сохранённые события и не гарантирует полноту данных внешнего игрового сайта.

### Правила выпуска, которые сохраняются для следующих версий
1. Перед публикацией: новый проверенный снимок Redis, фиксация текущего кода, конфигурации и deployment ID.
2. Изменения в отдельной ветке; все тесты и проверка браузера до merge.
3. Новая версия получает собственный номер, дату и список изменений.
4. Сборщики и Redis не перезапускаются при обычном выпуске сайта.
5. **Никакого автоматического отката.** По запросу пользователя откатывается выбранная версия кода; восстановление более старой базы отдельно согласуется во избежание уничтожения новых архивных данных.
