# Lucky Jet v0.2.13 — Telegram notifications for Strategy 2

Дата: 2026-11-08.

Резервная ветка кода до изменений: `backup/2026-11-08-v0.2.12-before-strategy2-notifications`.
Подтверждённый снимок Redis до изменений: `luckyjet-20261108T015021Z.rdb` (Railway backup volume).

## Изменения
- Добавлены уведомления о достижении порога ожидания (срабатывать после фактических подтверждённых раундов).
- Добавлены уведомления о первой реально рассчитанной виртуальной ставке; событие порога не считается ставкой.
- Добавлены уведомления о достижении целевого множителя с фактическими коэффициентом, числом ставок и финансовым результатом цикла.
- Необязательное уведомление об обнаружении нового опорного X (по умолчанию выключено).
- Отдельные пользовательские переключатели событий, звука и времени удаления; отдельное тестовое сообщение.
- Хранение настроек в Redis; дедупликация по ID исходного раунда; задачи Telegram изолированы от обработки архива.
- Сохранены расчёт ставок обеих стратегий, архив, сборщики и старые настройки первой стратегии.

## Техническая логика
- Уведомления рождаются только на переходах в зафиксированном DEMO ledger, а не из таймеров браузера.
- Исторический silent replay не создаёт уведомлений.
- Предшествующая успешная ставка может завершить цикл сразу в первом раунде: в этом случае уведомления «DEMO запущено» и «Цель достигнута» формируются отдельно.
- Сбой Telegram не прерывает сбор и обработку раундов.
- Отправка осуществляется в личный чат пользователя, имеющего действующий доступ.
