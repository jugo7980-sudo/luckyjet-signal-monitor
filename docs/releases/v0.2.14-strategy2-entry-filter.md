# Lucky Jet v0.2.14: фильтр входа стратегии №2

Резерв исходного кода: backup/2026-11-08-v0.2.13-before-strategy2-filter.
Исходный SHA: 71d7a8ae2a8beb349d5998c068c84e6a8477ab73.

Фильтр по умолчанию выключен для совместимости. В течение N ожидаемых раундов после опорного X считаются коэффициенты строго больше выбранного контрольного X. Если их число достигает настроенного количества, текущий сигнал отменяется, ставки не выполняются и стратегия ожидает следующего опорного X. После начала ставок фильтр не участвует в принятии решений. При восстановлении из сохранённого состояния и архива правило сохраняется.

Инварианты: оба DEMO-режима независимы, счётчик первого режима и фактический архив не меняются. История отменённых до первой ставки сигналов не считается историей совершённых ставок.
