◷С последнего выбранного X—Сколько завершённых раундов прошло после X для отсчёта.

↔Самое короткое расстояние—Минимальный промежуток между двумя искомыми X.
⇧Самое длинное расстояние—Максимальный подтверждённый промежуток между двумя X.
∑Средний коэффициент—Среднее значение всех коэффициентов в выбранных раундах.
★Самый высокий коэффициент—Наибольшее значение X в выбранных раундах.
↓Коэффициентов ниже 2x—Сколько выбранных раундов завершились ниже 2x.
◈В предыдущем периоде ≥ X—Сколько искомых X было в предыдущих N раундах.
±Изменение относительно прошлого—Разница в количестве X между текущим и прошлым периодами.

Найденные коэффициенты —

Сначала новые совпадения. Время фиксации показано по Владивостоку.

Что означают эти числа?

Найдено X — сколько раз результат достиг выбранного коэффициента.

С последнего X — сколько завершённых раундов прошло после совпадения. Для поиска и отсчёта могут быть разные X.

Расстояние между X — число раундов между двумя совпадениями. Если совпадение одно, вычислить расстояние нельзя.

Самая долгая серия без X — максимальное число подряд сохранённых раундов без выбранного коэффициента.

Сравнение периодов — разница между текущими N и предшествующими N раундами.

Если в архиве нет части результатов, мы их не восстанавливаем догадками. Сводка описывает прошлое и не предсказывает следующий коэффициент.
