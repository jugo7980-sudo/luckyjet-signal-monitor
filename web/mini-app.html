Результаты

◆Найдено ≥ X —Сколько раз искомый коэффициент встретился в выбранном периоде.
◷После X отсчёта —Сколько завершённых раундов прошло после X для отсчёта.
↗После искомого X —Сколько раундов прошло после последнего искомого X.
⌛Макс. серия без X —Максимальное число подряд сохранённых раундов без искомого X.
≋Средний интервал —Среднее число раундов между совпадениями. Нужно хотя бы два.
↔Мин. интервал —Минимальный промежуток между двумя искомыми X.
⇧Макс. интервал —Максимальный подтверждённый промежуток между двумя X.
∑Средний X —Среднее значение всех коэффициентов в выбранных раундах.
★Максимум X —Наибольшее значение X в выбранных раундах.
↓Ниже 2x —Сколько выбранных раундов завершились ниже 2x.
◈Прошлый период —Сколько искомых X было в предыдущих N раундах.
±Изменение —Разница в количестве X между текущим и прошлым периодами.

Справка

Найдено X — сколько раз результат достиг выбранного коэффициента.

С последнего X — сколько завершённых раундов прошло после совпадения. Для поиска и отсчёта могут быть разные X.

Расстояние между X — число раундов между двумя совпадениями. Если совпадение одно, вычислить расстояние нельзя.

Самая долгая серия без X — максимальное число подряд сохранённых раундов без выбранного коэффициента.

Сравнение периодов — разница между текущими N и предшествующими N раундами.

Если в архиве нет части результатов, мы их не восстанавливаем догадками. Сводка описывает прошлое и не предсказывает следующий коэффициент.
